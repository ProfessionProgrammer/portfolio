## 💻 Running Locally

Because the project is built with vanilla web technologies, there are no build steps required.

1. Clone the repository.
2. Navigate to the project directory.
3. Open `index.html` in your preferred web browser.

Alternatively, use a local development server like VS Code's **Live Server** extension or Python's HTTP server:

```bash
# Using Python 3
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
